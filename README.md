# 🐱 Gato y Crunchy — Pitch Bible Interactiva

Pitch Bible interactiva de **Gato y Crunchy**, creada por **Marc Gil Mayor**.  
Un viaje dimensional a través de la gestión emocional, la amistad y la convivencia.

---

## 📖 Sinopsis

Gato, un felino cascarrabias, metódico e hipersensible a los estímulos, vive una rutina ordenada en su apartamento. Todo cambia drásticamente cuando **Crunchy**, una criatura hiperactiva, caótica y adicta a las uvas, irrumpe a través de un portal interdimensional.

Juntos deberán aprender a gestionar sus diferencias emocionales mientras resuelven anomalías interdimensionales cotidianas y descubren el valor de la empatía.

---

## ✨ Características del Proyecto

- **Pitch Bible Interactiva:** Presentación visual estilo libro de arte animado / cartoon.
- **Efectos de Sonido & Diálogos:** Audio interactivo y voces con feedback sonoro (Web Audio API y SFX).
- **Efecto de Portal Interdimensional:** Canvas interactivo con vórtice de partículas y distorsión dimensional.
- **Diseño Responsive & Accesible:** Optimizado para lectura fluida, animaciones dinámicas e interacción en cualquier dispositivo.

---

## 🚀 Cómo Visualizarlo

Simplemente abre el archivo `index.html` en cualquier navegador web moderno, o sírvelo localmente con cualquier servidor estático:

```bash
# Con extensión Live Server en VS Code o usando npx

```
